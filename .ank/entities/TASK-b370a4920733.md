Preconditions to settle before claiming:

- Entire, as of 2026-10, is a **mirror** of a GitHub repository, not a host:
  GitHub stays the source of record, pushes are governed by GitHub's
  permissions, and the mirror is reached through an `entire://` remote
  served by Entire's CLI (docs.entire.io, guides/repositories/mirrors).
  Native hosting is announced, not shipped. So the Entire row measures a
  regional mirror in front of GitHub, and the interesting question is mirror
  safety: does a claim pushed through one region refuse a concurrent claim
  pushed through another, and what does GitHub end up holding. Confirm that
  `git push` through the `entire://` remote works from ank's subprocess (a
  remote helper must be on PATH) before counting the row as measurable; if
  it does not, the row is recorded as "not measurable with an unmodified
  ank" and that fact is the result.
- An Entire account with the GitHub App installed on the benchmark
  repository, mirrored in two regions.
- A second machine on the local network for the SSH bare repository.
- N = 50 against github.com may trip abuse protection: start low, space the
  runs, and note any rate limit as a measured fact.

Results are the proof of this task (human-review, the report itself) and
feed the phase 1 spec, whose amendment is a human act: the role `agent`
cannot edit an accepted spec, so the amended targets are proposed as a
superseding spec and ratified. Any competitor failure observed is a selling
point and is written down as such.
