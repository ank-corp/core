Agents pull and claim. Orchestration is an agent's job, as `ank-herdr` does it
today: an orchestrator that claims nothing assigns worktrees and identities, and
each worker runs the ordinary loop. The hub gives that orchestrator a fast global
view; it does not replace it.

A hub runner (verifier replay, integration, phase 3) is a process identity that
claims a task through the same push as anyone else. A human force-release
(phase 2) releases; it never claims on someone's behalf.
