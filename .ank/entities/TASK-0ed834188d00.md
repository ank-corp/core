Measure before building. The harness is reused by phase 1 acceptance (race
correctness at N = 50 over 1,000 trials against the hub), so it is a crate,
not a script.

Agents are processes, each with its own clone and `ANK_AGENT`, running the
ordinary loop through the installed `ank` binary (0.9.0 at the time of
writing). The synthetic corpus is generated by the harness: a handful of open
tasks with disjoint scopes, plus one contended task every agent claims at the
same instant for the race.

Lease skew is not measured: ank's code answers it (reader's local clock, two
minutes tolerance), see ADR-85a8e6f696ea.
