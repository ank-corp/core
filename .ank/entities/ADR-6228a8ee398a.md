Open core follows cost: what costs money to run is compute, not code. The hub
binary is open and self-hostable; the hosted service sells hosting, runner
minutes and organisation-level management, on the same binary.

A dependency on an external service at startup (a database server, a message
broker, an object store) would make self-hosting a project rather than a
command, and would fork the hosted and self-hosted builds. Storage is embedded
(SQLite in WAL mode for refs and metadata, content-addressed files for
objects), revisited only on measured need.
