AnkHub will be several repositories. The question this decision answers is
which axis splits them. It is not "one service per function": ADR-6228a8ee398a
(one binary, self-hostable, the same for ankhub.com) and ADR-25e7078ec73a
(modular monolith, crates are the future service boundaries) already forbid
that for the hub itself. The axis is: what a self-hosted hub needs, versus
what only the hosted offer needs.

Two tests, either of which puts a capability in core:

1. **A self-hosted hub needs it to run.** Identities, the audit log, the
   allowed-signers registry, attestation ingestion, the replay and integration
   executor, the PR gate, continuous `check`: an organisation running its own
   hub wants all of these on its own machines.
2. **It reads or writes the store's sequence.** The git front, the event
   stream, the audit log, lease expiry on revocation. Separating any of them
   from the store means either a distributed consensus between processes or a
   copy of the sequence that can diverge, which is what the opportunity report
   rejected when it rejected Redlock and Raft.

What fails both tests lives outside core: accounts and billing, the scheduler
that shares runner capacity across tenants, enterprise directory sync. These
wrap the binary (its HTTP API, its configuration, its data directory) and
never patch it.

Direction, not decided here (the ADR that creates the second repository
records it): `ank` stays the CLI; `core` is the hub; `web` holds the reader and
ratification queue, whose built static assets are embedded in the binary at
release so a self-hosted hub ships them too; `cloud` and `infra` hold the
hosted-only services and the deployment. None of these is created empty: each
is born with its first task, as crates are (ADR-25e7078ec73a).

The one boundary expected to move is the runner: the executor that replays
verifiers stays in core as a subcommand of the binary, because a self-hoster
must be able to replay proofs locally; the scheduler that multiplexes shared
compute moves to the hosted side when its load justifies it.
